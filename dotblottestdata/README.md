# Local Dot Blot Test Data

This folder is intended for local real-world blot images used during development and validation.

The image files inside this folder are ignored by Git on purpose, so personal or experimental data is not committed accidentally.

Recommended contents:

- PNG exports from scanners or imaging software
- raw TIFF files
- additional test blots for PVDF and nitrocellulose membranes

If you want to share a specific example image publicly later, move or copy a curated version into `sample_data/` instead.
